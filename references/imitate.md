# 模仿参考视频

用户发来一条喜欢的视频（模板库、别人的爆款、自己以前的作品），要用自己的素材做出「同款」。要仿的是**剪辑结构、节奏、版式**，不是照抄内容。

## 1. 拆解

```bash
python scripts/analyze_reference.py 模板.mp4 --project P
```
数字部分自动得出：

| 项 | 用途 |
|---|---|
| 剪辑点、每镜时长、中位数 | 换装节奏 |
| BPM、第一拍位置 | 选配乐 |
| 剪辑点间隔（以拍计）和抖动 | 抖动 <0.12 拍：严格卡拍；0.12–0.3 拍：大体每 N 拍一换，具体时机跟着动作走（遮挡转场常见）。我们的版本一律精确卡在拍上——更整齐，观众感受一样 |
| 剪辑点相对鼓点的固定偏移 | 正常现象：转场在运动中段换画面。甩镜的模糊峰值本来就对准拍点，不用模仿这个偏移 |
| 音乐「进入」的时间 | 钩子时长 |
| 建议参数 | `beatsPerLook`、`finaleBeats` |

然后**亲眼看图**补全数字看不出的东西：
- `sheet.jpg`（每秒 4 帧）
  - 开头有几秒钩子、钩子上写了什么、什么字体颜色描边、放在画面哪里
  - 每段是不是一套新衣服、模特怎么走（朝镜头走来 / 横穿 / 原地转身）
  - 结尾怎么收（定格？品牌？直接结束？）
- `cut_0.jpg` 等（剪辑点前后各 0.45 秒、每秒 30 帧），用来判断转场类型：
  - **遮挡转场**：画面被柱子、墙、路人、车扫过，在完全遮住时换衣服。拍摄时就设计好的。
  - **甩镜**：横向动态模糊带过
  - **硬切**：前一帧和后一帧直接不同
  - **闪白 / 缩放**：中间有白帧或明显放大

## 2. 映射到我们的素材

| 参考视频里的 | 我们怎么做 |
|---|---|
| 遮挡转场（柱子、墙扫过） | 素材里没有遮挡物 → 用 `transition: "whip"` 甩镜模拟，峰值落在拍上；要跟用户说明这是模拟 |
| 甩镜 | `whip`，方向用 `whipDirection` 对齐 |
| 卡拍硬切 | `transition: "cut"` |
| 闪白、缩放冲击 | 默认不仿（这个受众不喜欢），先问用户 |
| 每套 N 拍 | `beatsPerLook: N`（多为 4） |
| 结尾停留 | `finaleBeats`（多为 8，品牌卡占后一半） |
| 钩子 2 秒、音乐压着 | 钩子长度 = 一个 `beatsPerLook`；脚本自动给钩子段的音乐做低通和降音量 |
| 钩子字样式 | `hookColor` / `hookStroke`；版式在 `assets/template-combo-overlay.html` 的 `.hook-line` |
| 钩子文案 | 仿句式，换成我们的内容（见 aesthetic.md 第 7 节） |
| 原曲 | 不直接用别人的音乐；生成 / 找同 BPM 的曲子，告诉用户发布时可在抖音「使用同款音乐」 |

钩子下面的画面：参考视频常用「花絮感」镜头（摄影师在拍、模特在准备）。没有这类素材时，用合集最后一套衣服的远景走来镜头，等于先预告。人要离得够远，钩子字不能挡脸（脚本会报警）。

## 3. 选段

- 每套挑一个**朝镜头走来的全身镜头**做该套的段落，偏移选在步态最好看的地方。
- 偏移至少 0.25 秒，给甩镜留预卷；从偏移开始要有 `beatsPerLook` 拍外加 0.25 秒的可用长度（不够时脚本会报错，说明还差多少）。
- 合集顺序：开头放最吸睛的一套，中间深浅色交替，压轴放最有记忆点的。
- 可以混用不同日期拍的素材（用户说过「组合的也可以使用昨天的原片」）。
- 分主题出多条：外套篇、针织篇、通勤篇……每条 5 套左右。

## 4. 构建与验收

```bash
python scripts/render.py combo A B --project P
```
审片图 `review/render_combo_A.jpg` 依次给出：
- 钩子
- 第一次换装前 0.25 秒、换装瞬间、换装后
- 每套中间
- 结尾

要确认：
- 甩镜的模糊帧落在换装点
- 钩子字没挡住头
- 「第 N 套」标签和衣服对得上
- 音乐在第一次换装时进入（可以用 ffmpeg 看响度曲线，那里会有一个明显的跳升）

# 风格克隆：照着一条视频「原样」拍一条

用户说「这条的滤镜、风格、音乐都很好，照着做一条，音乐直接用它的」，要的不是换装合集，而是**同长度、同剪辑点、同音乐、同色调**的一条片子，用一套衣服。

## 1. 拆解

```bash
python scripts/analyze_reference.py 模板.mp4 --project P              # 0 个剪辑点时加 --threshold 0.12
python scripts/contact_sheet.py pace 模板.mp4@3.0 ac97@0.5 --project P # 对比步频
```

看 `sheet.jpg` 回答四个问题：
- **几套衣服？** 通常一套贯穿全片。
- **怎么拍的？** 长焦街拍朝镜头走来 / 横穿 / 停步回头。
- **有没有字？** 风格类模板常常一个字都没有。
- **是不是慢动作？** 看 `pace.jpg`：正常走路每秒约 2 步，参考每秒 1.2–1.5 步就是 0.6–0.7 倍速。
- **核心动作是什么？** 比如「背对镜头走→回头→微笑」。在全部素材里找同样的动作：可以逐个片段看人体朝向（肩膀左右顺序会翻转）找回头时刻，再出 0.2 秒间隔的条带图确认。动作对上了，比衣服和场景对上更重要。

## 2. 选素材

- **衣服的明暗、冷暖要像参考**：全黑长焦冷调 → 深色皮衣、黑裤；米色暖阳法式 → 棕色系、金色阳光下的镜头。
- **镜头数量和参考一致**：每段时长 = 参考对应段的时长。慢动作写在 EDL 上：`["0017", 6.9, 4.933, {"speed": 0.7}]`，时长是成片秒数，实际消耗原片 4.933×0.7 秒。慢动作要求原片是 50/60 fps。
- **景别和动作尽量对应**：参考第 1 段走下台阶，我们也挑走下台阶的段落；参考最后一段是近景，我们也用近景收尾。

## 3. 调色：把参考的「滤镜」做成 LUT

```bash
python scripts/match_look.py build 模板.mp4 --name cool306 --shots c1_0 c1_1 ... --project P [--tone 0.55]
python scripts/match_look.py apply cool306 c1 --project P
```

- 看 `review/look_cool306.jpg`，三栏分别是我们的原图、调色后、参考。
- 参考整体很暗或很亮、但那是**内容造成的**（黑衣服、夜景、白墙）时，把 `--tone` 降到 0.5–0.6。否则我们较亮的场景和脸会被压暗。
- 肤色默认只吃一半的色偏（`--skin 0.5`），冷调下脸不会发青。
- 调色按色相分区匹配：
  - 暖色（皮肤、土地、橙色）、绿色（树叶）、冷色（天空、青色）各自往参考同区的色相和饱和度靠。所以「橙青」类滤镜能把蓝天变成青色，同时把中间调变暖。
  - 参考里几乎没有绿色时（复古、胶片感），绿叶会往暖色偏，变成橄榄色。
  - 接近灰色的颜色（灰路面、白墙）不进任何分区，只往参考同亮度的底色融合，比如变成金棕色路面，不会被参考的高饱和度放大成蓝灰。
  - 底色融合有三道保护：
    - 偏色量最多到色度 14。参考的平均色很浓，往往是因为画面里有阳光下的树叶、油菜花这些内容，不是因为滤镜。
    - 偏蓝的灰色（阴天、薄云的天空）只吃四分之一的偏色。
    - 接近白色的灰（白云、白墙）也只吃一小部分，跟胶片保留高光的效果一样。
  - 用来测量的是调色后的原镜头（`shots/`），不是美颜输出，所以美颜还在跑的时候也能生成滤镜。
- 先美颜再上 LUT（LUT 作用在 `shots_beauty` 上）。

## 4. 音乐：直接用参考的原声

先确认参考真的有声音：`analyze_reference.py` 会报 `soundtrack: SILENT`。抖音下载的视频常常只有一条静音音轨，音乐是作者在平台上加的。这时没有音乐可复制，`build_clone.py` 会直接报错；改用 music.json 里的曲子，并告诉用户发布时在抖音选歌。

`clones` 配置里 `"music": "reference"`：
- 从参考视频里原样取出原声，从 0 秒开始，和剪辑点一一对齐
- 只做一次整体增益到 -14 LUFS，不压缩动态
- 存成 WAV，避免 AAC 编码器延迟造成的 20 ms 错位

**跟用户说清楚**：参考视频的配乐大多是商业音乐，原样搬进自己的视频，在抖音可能被版权识别、静音或限流。最稳的做法是发布时在抖音里给这条视频选同一首歌（「使用同款音乐」），把视频原声调到 0。成片的剪辑点和原曲对齐，换成同款不会错位。

## 5. 字幕

参考没有字，就别加花字。只留一行安静的品牌小字；长一点的片子（15 秒以上）结尾加品牌卡（`"captions": "brand+end"`），7 秒左右的短片只留品牌名（`"brand"`）。

## 6. 构建与验收

```bash
python scripts/render.py clone A B --project P
python scripts/finalize.py --project P --out <成片> --singles --combos --clones A B
```

审片图给出每段中间帧和结尾。要确认：
- 色调和参考一致、各段统一
- 慢动作流畅
- 品牌字没压头
- 没有举手机看手机
