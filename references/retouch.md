# 美颜与身形修饰

`scripts/beautify.py` 读 `assets/shots/`（已调色），写 `assets/shots_beauty/`；构建脚本优先用美颜后的镜头。

## 原理（出问题时知道看哪里）

1. **追踪**（每帧，结果缓存在 `<project>/cache/*.npz`）：
   - MediaPipe 人体姿态（33 点）
   - 用姿态找到头部，裁出来放大到 512×512，再跑人脸网格（478 点）——全身镜头里的小脸也能追到
   - 多类别人像分割，分出脸部皮肤和身体皮肤
2. **时间平滑**：所有关键点做零相位高斯平滑；追踪丢失的帧插值补齐，效果强度在丢失处自然淡出。所以修饰不会抖、不会忽有忽无。
3. **处理**：
   - 颜色类（磨皮、美白、口红、腮红、眼线）在 Lab 空间做，只在面部区域
   - 几何类（瘦脸、大眼、瘦身、拉腿）合成一张形变图，一次重采样完成，画质只损失一次

## 默认强度

| 参数 | 默认 | 作用 | 调整建议 |
|---|---|---|---|
| `smooth` | 1.0 | 面部皮肤边缘保持磨皮（不碰眼眉唇） | 0.6 更轻 |
| `texture` | 0.45 | 磨皮后加回的细纹理比例 | 低于 0.3 会像塑料 |
| `tone` | 0.5 | 均匀肤色（淡化红斑色斑） | |
| `brighten` | 9 | 中间调提亮（已很亮的皮肤自动不提） | 5–12 |
| `deyellow` | 0.85 | 皮肤去黄（b* 乘数） | 1.0 = 关闭 |
| `lip_a` / `lip_b` / `lip_dark` | 0.55 / 0.40 / 6 | 拉向自然红，随脸部亮度收敛 | 想更淡把 0.55 降到 0.4 |
| `blush` | 7 | 腮红（a* 增量），转向另一侧的脸颊自动减弱 | 5–9 |
| `liner` | 0.6 | 上眼线，外眼角带小翘 | 0 = 关闭 |
| `eye_big` | 0.13 | 眼部局部放大 | 0.08 更自然，>0.18 容易怪 |
| `face_slim` | 0.065 | 下颌线向中线收（整条线连续平滑） | 0.04–0.08 |
| `waist` / `hip` / `thigh` / `shoulder` | 0.06 / 0.05 / 0.04 / 0.02 | 按身体行分区横向收窄 | |
| `legs` | 0.04 | 胯到脚踝纵向拉长，向下延伸，头不上移 | 0 = 不拉高 |

改法：在 `config/retouch.json` 写要改的项，比如 `{"eye_big": 0.08}`，再跑 `beautify.py`。脚本会自动判定所有镜头过期并重做。

## 自动跳过 / 减弱的情况

- 眼睛宽度不到约 10 像素，或侧脸透视太强：不做眼线和大眼。远景、侧走镜头属于这种。
- 胯部不可见（半身近景）：不瘦身、不拉腿。
- 胯部在画面下 20%：不拉腿。
- 某些帧追踪丢失：效果淡出再淡入，不会突然跳变。

## 预览与验收

```bash
python scripts/beautify.py --preview 03_1 06_0 --project P
```
会生成 `review/beauty_<key>_<帧>.jpg`（整帧，左右对比）和 `_face.jpg`（脸部放大两倍）。验收要点：
- 本人一眼认得出：五官比例、表情、痣都还在
- 皮肤有纹理，头发、衣服、背景没有被磨糊
- 口红在暗光镜头里不发亮（暗光镜头单独挑一个预览）
- 眼线细、不脏，没有画到眼皮褶子外
- 背景里的栏杆、栅栏、台阶没有被拉弯

## 速度

- 首次处理：每个镜头约 1–3 分钟，主要花在追踪上
- 有缓存后：每个镜头约 40 秒
- `--jobs 3`：3 个进程并行，每个约占 1.5 GB 内存
- 只改了 `retouch.json`：追踪缓存继续有效，不用重新追踪

## 诚实

脚本做不到的，在剪映里补也要明说：比如特写里的局部瑕疵修补、牙齿美白、发型修饰。不要声称做了没做的修饰；也不要建议用户在剪映里再开一遍美颜，两遍叠加会变假。
